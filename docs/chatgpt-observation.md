# ChatGPT.app 只读观察开发候选

当前源码候选为 0.1.2-dev.0，ChatGPT 适配子包为 0.1.0-dev.0。已发布的 DSH 版本仍为 0.1.1。本页说明当前开发状态，不能作为正式 ChatGPT 安装或完整监控通过的证明。

## 当前能力

当前阶段将真实主会话生命周期接入生产只读适配器、共享核心 HTTP 和鉴权 MCP 面板。面板明确显示“六项分析尚未接入”，不会用模拟结论或开始事件证明任务正常。

适配器通过每次请求的原生线程身份绑定当前主聊天。它使用公开只读元数据及版本锁定的本机记录，核对 App 所属执行进程、启动代次、版本、插件资格和文件身份。来源在读取期间失效时丢弃晚到状态。

同一安装与 App 执行域共用一个来源。主聊天以独立线程身份区分；项目资格失效只撤销对应任务，全局停用或 App 失效才关闭整份来源。当前不自动发现全部聊天，也不读取分叉及子代理材料。

当前读取配置仅核验过 ChatGPT 26.1007.71326（20398）与 bundled native 0.162.0-alpha.17.2。未知版本保守显示缺口。公开元数据服务的 notLoaded 状态不能替代实际桌面执行状态。

## 开发入口

从仓库 checkout 准备依赖；ChatGPT 子包与 DSH 包分开管理，DSH 包仍使用宿主 SDK，不新增 npm 运行依赖。

```sh
npm ci --ignore-scripts
npm ci --prefix chatgpt --ignore-scripts
npm run test:chatgpt
```

辅助进程从私有安装配置启动。配置由 prepareInstallation 创建，要求明确的适配器数据目录、核心数据目录及插件身份；不会默认接管日常 DSH 配置。

```sh
node chatgpt/run.mjs --config /absolute/path/to/private/installation.json
```

这是本机辅助进程的内部启动入口。用户查看入口仍在 ChatGPT 会话侧面板。当前没有注册登录服务、安装或签名 App，正式安装器与运行期恢复由后续阶段交付。

安装目录使用私有权限，配置和生成的 MCP 连接保存私有令牌。令牌不进入工具结果、诊断、观察事件或通知。缺少可信插件启用状态时拒绝读取；准备配置本身不会启用宿主插件。

## 验证范围

确定性检查走受控原生 IO、真实文件读取、生产适配器、真实共享核心 HTTP、鉴权 MCP 及页面桥接。只替换外部 IO，来源状态、读取预算、取消、事件归属和核心业务真实执行。

私有 HTTP 认证已通过受控客户端及上述桌面版本的实际会话面板验证。当前聊天和另一条已核实的本机主聊天完成了切换与重开检查，面板身份随聊天切换；真实记录经生产适配器进入私有核心，仍以灰色表示尚无分析结论。这是两条主聊天的有限样本，不代表全部聊天、分叉或其它宿主版本已经覆盖。

本轮新插件先在后台显示已安装、已启用，但 App 面板加载失败；用户在 App 内停用再启用本插件后恢复，随后完成真实观察验证。安装流程须分别核对后台登记与实际入口，不能把后台的启用状态当作 App 已就绪，也不能把这一次恢复步骤当成所有加载错误的通用原因。

冷读期间可能先显示 current-turn-not-observed：会话身份已经确认，当前执行仍需在已读记录中核对。来源、记录或版本无法核实时保留缺口。正式后台、原生通知和 App 退出恢复仍保留独立实测门禁；本轮没有安装常驻服务或重启宿主。

后续范围包括全部本机主聊天与分叉、真实请求及六项分析、会话级持久暂停、首次失败提醒、24 小时已监控历史，以及单实例后台、升级和按来源卸载。模型准确度和显卡推理速度不作为框架验收门槛。
