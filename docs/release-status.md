## v0.1.1 已发布基线

本版发布共享核心、分析模块及 DSH 适配器。运行代码沿用已通过框架验收的 `0.1.0-dev.16`；正式版本的修改限于版本号、发布文档及源码测试的可移植性。Codex 适配器后置。

### 已完成的框架验收

- 本地 Node.js 24、26 完整测试各 434 项，资源检查各 71 项，以及语法和实际 DSH 包加载检查。正式版本另行对最终输入复验，结果随发布资产提供。
- 专用 DSH Host 中的 4 个主会话、12 个后代及四层结构真实采集；两阶段材料更新、逐代理身份与证据隔离、共享调度和单调用准入。
- 实际后台观察的 125 帧、2,000 次范围核对及 206 对 RPC 对照；16 个代理均取得分析机会。暂停分析期间仍采集，恢复后继续调度。
- 全局会话分组、当前会话 GS、后代范围与所属路径、只读顶部备用入口、短依据、隐藏正常及历史节点展示；补充实测确认绿色节点筛选仍保留必要祖先路径。
- 所有自有测试代理自然结束，临时驱动卸载，资源收尾及监控配置按修订号条件恢复。日常使用实例未参与测试。
- 合并通知、重复间隔、失效与提交状态的边界检查；此前真实宿主已提交四条长等待合并通知，用户确认看到对应通知。该有限实机证据与本版相关通知逻辑的逐段一致性复核一并保留。

上述数量用于说明证据范围。最终一轮未新增实际通知，也没有在真实宿主中观察到本轮取消／晚到请求；对应行为由既有边界测试覆盖，不将其表述为新一轮实机通过。

### 发布承诺的边界

根据最终确认，本次验收关注框架是否持续采集、隔离材料、公平调度、正确显示状态、处理通知并回收资源。模型判断准确度、GPU 拥堵及推理耗时不决定本次框架验收，也没有给出固定的 16 代理推理时延承诺。

历史有限题集的 36/36 结果来自当时的模型组合，不代表当前或任意模型的准确率，不作为本版质量保证。六项检查、协议与引用校验保留；模型失败、unknown、覆盖不足和等待必须如实显示。

真实安装验收使用具备分页及父代理等待审计扩展的 DSH SDK。扩展未随本包发布；普通宿主缺失时显示缺口，见 [兼容性说明](installation.md)。逐后台安装不等于整机自动发现，跨后台自动装配及 Codex 插件均未包含。

发布内容不含真实会话摘录、本机连接令牌、模型配置和临时测试驱动。源码中的模型与宿主替身使用合成材料；旧核心快照只用于兼容性回归，不进入运行安装包。

## 发布流程与完成条件

### 发布前

发布使用当前本地 `main`。先按 [开发与验证](../README.md#开发与验证) 准备锁文件依赖及已构建的 DSH SDK，完成最终待提交内容的 `npm run check`、`npm test` 和 `npm run test:resources`。记录源码版本、验证命令和真实退出码；全部通过后才提交、推送或触发远端 CI。本地无法执行的检查须先列明缺口，取得用户明确的远端补验授权；已知本地失败先修复。

0.1.2 还须记录两端安装产物与最终源码的对应关系、7 张工单的受影响功能结果、真实候选和最终交付复核。尚未完成的项目逐项保留；本轮不执行的升级专项不得记为通过。旧输入上的成功结果只在输入与环境未变且不受本次修改影响时复用。

发布前确认实际发布 workflow、版本 tag 和预期资产清单。资产名称随 `package.json` 的名称和版本变化，至少包括对应版本的 `.tgz` 安装包和 `SHA256SUMS`，以及本次发布约定的验证报告。保留发布前已有的打包及包内容检查；构建输入变化后更新对应产物。

### 发布后

以下条件全部满足，才可报告发布完成：

- Actions：对应发布 tag 和实际提交的必需 GitHub Actions run 全部完成，结论为 `success`。排队、取消、跳过、失败或证据缺失均保留未完成。
- Release：对应 tag 的正式 Release 已创建，既非草稿也非预发布；tag、包版本和 Release 版本一致，tag 指向实际发布提交。
- 远端资产：通过 Release 的资产列表核对预期清单，名称和版本正确，资产齐全且大小均大于零。构建及资产校验结果以对应成功的 Actions 记录为依据。
- 本地同步：先更新涉及的本地分支，再从对应本地分支推送。远端更新后，以 fast-forward 同步所有涉及的本地分支，并核对本地与远端 tag 的对象及解引用提交一致。结束前检查当前工作区状态，记录各对应分支和 tag 的完整提交哈希；对应引用须一致，当前分支不得落后。多个目标分支应保持同一提交时，逐一核对同一完整哈希。

同步遇到分叉、tag 冲突或用户文件阻碍时，报告具体引用和阻塞文件并停止。用户未明确授权时，不自动 stash、移动、删除或覆盖用户文件，也不强制改写引用。

发布后默认只读取远端状态和资产元数据。下载发布资产到本地、重新计算哈希、安装或运行，仅在用户另行明确要求时执行，不作为默认发布完成条件。交付时给出 Actions、Release 链接和本地同步结果；缺少任一完成条件时，明确列出未完成项。
