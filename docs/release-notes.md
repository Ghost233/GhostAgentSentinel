# 版本说明

## 0.1.2 · 待发布候选

本轮计划以同一 0.1.2 正式版本发布 DSH 与 Codex。当前仍在完成最终构建、功能验证、实机和交付复核，尚未创建正式 Release。已发布正式基线为 0.1.1；旧 `0.1.2-preview.2` 为开发预览，不属于正式 Release。

- 修复共享核心恢复大历史序号时触发的 `RangeError`，保留原有身份、去重、只读范围和留存要求。Codex 继续只观察本机主聊天及分叉主会话。
- 每份安装独立保存总结模型和 JEV 判断模型，同一安装内各聊天共用。DSH、Codex 正式版与名称以小写 `test` 结尾的测试版共用核心，分别管理配置及暂停。
- Codex 会话面板顶部固定提供“设置”，采集失败时仍可操作。两个模型分别设置服务地址与 ID，支持目录选择和手填；连接检查只读取 `GET /v1/models`，不发送聊天材料或推理。
- 总结模型整理证据并生成附依据的 1～2 句执行短总结。仅本轮总结模型和 JEV 均成功，且输出与引用有效时发布新总结；失败或未完成时保留实际状态，旧总结按历史显示，unknown 保持不可判断。
- 保存配置只取消本安装的旧分析，并忽略晚到结果，活动任务按新配置公平排队。服务离线时继续采集并退避恢复，不解除手动暂停，不下载、更换或启动模型。
- DSH 的暂停只作用于本安装。安装暂停与单聊天暂停取逻辑或，恢复一项不解除另一项，其它安装继续运行。

旧共享模型配置需要重新手填，本轮不迁移、导入或兼容旧格式，也不删除其它观察资料。DSH 安装包目标为 `ghost-agent-sentinel-0.1.2.tgz`，Codex 通过仓库市场安装；正式与 test 安装保持独立身份。

本轮按用户确认不执行升级专项验证，相关项目保留为未执行。真实 App 退出重开仍为最后的交付门禁，尚未执行；历史预览版与局部测试结果不自动覆盖本候选。最终验收范围和发布状态见 [发布验证范围](release-status.md)。

## 0.1.1 · 2026-10-15

首个正式发布的 DSH 框架版本，包含本机只读采集、共享核心、六项检查及多级代理观察。

- 右侧全局总览按主会话分组；当前会话通过紧凑 GS 入口查看自身及后代。两处界面突出问题、支持隐藏正常，依据紧随对应节点。
- 绿、黄、红、灰四类状态独立计数，区分静默、合理等待、告警与覆盖缺口；已结束代理退出运行计数，仍运行的后代保留。
- 子代理使用委派任务和有效用户限制，材料及引用按代理隔离；公平轮流分析，独立冷却 60 秒，可复用条件未变的有效结果。
- 同主会话告警最多等待 3 秒合并，同问题重复通知至少间隔 10 分钟；面板关闭后后台持续。
- 观察资料滚动保留 24 小时，显式敏感字段省略，资源有界回收，取消后忽略晚到结果。

安装文件为 `ghost-agent-sentinel-0.1.1.tgz`，通过 DSH 第三方插件入口选择解压后的 `package` 目录。本版不发布到 npm，不启动或附带模型服务，不修改宿主 SDK。

运行代码与已验收的 `0.1.0-dev.16` 相同。完整宿主能力要求及验收局限见 [安装说明](installation.md) 和 [发布验证范围](release-status.md)。

`v0.1.0` 的源码 tag 保留，但未创建正式 Release：首次远端门禁发现本机 Homebrew Node 与官方运行时使用不同 zlib，导致压缩包哈希不同。v0.1.1 固定官方 Node.js 24.21.0 与 npm 11.19.1，并让 npm 子进程使用同一 Node，修复发布构建一致性；运行代码保持不变。
