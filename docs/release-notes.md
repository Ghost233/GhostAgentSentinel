# 版本说明

## 0.1.0 · 2026-10-15

首个 DSH 框架版本，包含本机只读采集、共享核心、六项检查及多级代理观察。

- 右侧全局总览按主会话分组；当前会话通过紧凑 GS 入口查看自身及后代。两处界面突出问题、支持隐藏正常，依据紧随对应节点。
- 绿、黄、红、灰四类状态独立计数，区分静默、合理等待、告警与覆盖缺口；已结束代理退出运行计数，仍运行的后代保留。
- 子代理使用委派任务和有效用户限制，材料及引用按代理隔离；公平轮流分析，独立冷却 60 秒，可复用条件未变的有效结果。
- 同主会话告警最多等待 3 秒合并，同问题重复通知至少间隔 10 分钟；面板关闭后后台持续。
- 观察资料滚动保留 24 小时，显式敏感字段省略，资源有界回收，取消后忽略晚到结果。

安装文件为 `ghost-agent-sentinel-0.1.0.tgz`，通过 DSH 第三方插件入口选择解压后的 `package` 目录。本版不发布到 npm，不启动或附带模型服务，不修改宿主 SDK。

运行代码与已验收的 `0.1.0-dev.16` 相同。完整宿主能力要求及验收局限见 [安装说明](installation.md) 和 [发布验证范围](release-status.md)。
