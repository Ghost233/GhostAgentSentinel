# 各安装独立配置总结与判断模型

2026-10-19，用户已最终确认本轮完整需求。每份安装分别保存模型配置，同一安装内各聊天共用。正式 Codex、DSH 与 test 可以选择同一个模型服务，修改一份安装的配置应只影响该安装。共享核心继续复用，配置归属独立于聊天和面板。这一选择修正了现有核心仅持有一套模型连接的行为，避免测试或单端配置修改影响其它安装。

用户选择直接重新配置模型，不处理旧模型配置，不做迁移或旧配置格式兼容。因此不提供“复制现有配置”，也不自动导入旧共享配置。此决定针对模型配置，不授权删除其它历史资料，也不撤销双端共用核心及互不影响的要求。

总结模型负责整理证据，并生成附依据的 1–2 句当前进展或需关注问题的总结。JEV 判断模型继续负责六项检查的判断，共配置两个模型。

模型选择先读取服务的模型列表，并保留手填模型 ID。连接检查仅核对服务在线和模型名称，不发送合成推理请求。在线与模型可见不证明实际总结或判断调用成功。

本轮总结与 JEV 实际调用都成功后，才发布新的完整总结。任一环节失败时显示故障，旧总结保留在历史中，不充当本轮结果。

服务离线时保留配置并继续采集，按退避间隔重新检查。同一服务和模型恢复后自动恢复分析，仍遵循插件启用资格及手动暂停规则。不自动更换、启动或下载模型。

保存配置后，取消该安装的旧分析并忽略晚到结果，活动任务按新配置重新进入公平队列。采集和原任务继续运行，其它安装不受影响。

当前会话侧面板固定提供设置入口，分别显示采集、各模型连接和通知状态。未配置时可直接进入配置；采集失败时设置仍可打开，并说明失败环节。上述决定已进入 0.1.2 源码候选，实际候选验收尚未完成，不能据此宣称现有预览版可用。
