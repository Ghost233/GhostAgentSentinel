# GhostSentinel test

从仓库市场安装并在 App 中启用。关闭面板继续观察；停用插件停止观察。首次启用会校验并解压包内运行环境，无需 npm 或独立常驻程序。

安装版本：0.4.9。在同一插件的全局安装设置面板中分别配置总结模型和 JEV，完成有效模型组编辑后自动保存。本安装的聊天共用配置，其它安装独立。连接检查只核对在线和模型名称。三条摘要合并后先显示，JEV 判断及依据随后更新。JEV 超时仍保留摘要。材料有缺口时显示观察范围。仅支持已核实版本的 macOS Apple Silicon ChatGPT.app。

安装、资料位置、验收范围和完整清理步骤：https://github.com/Ghost233/GhostAgentSentinel/blob/test/docs/chatgpt-github-installation.md
