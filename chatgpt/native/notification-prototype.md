# 一次性通知原型

设计问题：通知如何让用户认出聊天、理解问题并进入正确会话？

提供 A 聊天优先、B 问题优先、C 合并摘要三个方案；2026-11-08 用户明确选择 A。生产实现采用 A 的聊天名称优先、状态副标题、原因与影响短句，以及按通知身份跳转。跨聊天汇总列表仍只属于 C 原型，不纳入本次实现。

在仓库根目录运行 `node chatgpt/native/notification-prototype.mjs`，打开 `http://127.0.0.1:5198/notification-prototype?variant=A`。使用底部开关或左右方向键切换方案。示例数据与导航状态只在内存中，不调用真实聊天、模型或系统通知；macOS 控制真实通知框的外观。

这三个文件仅为设计一手来源，不应合入正式插件。
